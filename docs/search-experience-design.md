# 검색 경험 설계

## 개요

ContextHub 검색 UX의 세부 동작을 정의한다.
출처 표시, 문서 검증, Retrieval Progress, Chunk 상세 패널을 포함한다.

---

## 1. 검색 입력 설계

### 검색창 동작

```
입력 중:
  - 최소 2자 이상 입력 시 [문서 탐색] 버튼 활성화
  - Enter 키로 즉시 실행
  - Ctrl+K 단축키로 포커스

입력 직전 (debounce 없음):
  - 실시간 자동완성 없음 (MVP)
  - 이전 검색어 히스토리 없음 (MVP)

검색 실행 시:
  - 버튼 비활성화 + 로딩 스피너
  - 이전 검색 결과 초기화
```

### 에이전트 선택과 검색 연관성

```
에이전트 선택 → 필터 기본값 변경 → 검색 범위 변경

NAS RAG 에이전트 (현재 유일):
  검색 범위: NAS 전체 색인
  권한 필터: 사용자 권한 기반
  정규화: retrieval_query.py 규칙

(Phase 3) 로그 분석 에이전트:
  검색 범위: 로그 데이터셋만
  권한 필터: 별도 정책
  정규화: 다른 규칙
```

## 2. 문서 카드 상세 설계

### 점수 바 색상 규칙

| top_score 범위 | 색상 | 의미 |
|--------------|------|------|
| 0.80 이상 | 🟢 녹색 | 높은 관련성 |
| 0.60 ~ 0.79 | 🟡 주황 | 중간 관련성 |
| 0.60 미만 | 🔴 회색/빨강 | 낮은 관련성 |

```
점수 0.87:  ████████░░  (80% 채움, 녹색)
점수 0.61:  ██████░░░░  (61% 채움, 주황)
점수 0.43:  ████░░░░░░  (43% 채움, 회색)
```

### 카드 선택 상태

```
미선택:
┌──────────────────────────────────────┐
│ ☐  ID_P05_테일러링내역서.pdf          │
│    ████████░ 0.87                    │
└──────────────────────────────────────┘

선택됨:
┌──────────────────────────────────────┐ ← 테두리 강조
│ ☑  ID_P05_테일러링내역서.pdf          │
│    ████████░ 0.87  ✅ 선택됨         │
└──────────────────────────────────────┘

답변 생성 기준으로 사용됨:
┌──────────────────────────────────────┐ ← 배경색 강조
│ ☑  ID_P05_테일러링내역서.pdf          │
│    ████████░ 0.87  🔍 답변 기준      │
└──────────────────────────────────────┘
```

### 카드 클릭 vs 체크박스 선택

| 인터랙션 | 동작 |
|---------|------|
| 체크박스 클릭 | 문서 선택/해제 (답변 생성 대상) |
| 카드 영역 클릭 | 우측 패널에 Chunk 상세 표시 |
| 카드 더블클릭 | 체크박스 토글 |

## 3. Retrieval Progress 패널 상세

### 패널 위치 및 표시 조건

```
DISCOVERING 상태 → 문서 카드 목록 위에 표시 (항상)
GENERATING 상태  → 답변 패널 위에 표시 (항상)
ANSWERED 상태    → 축소됨 (클릭 시 펼치기)
```

### 단계별 상세 표시

**1단계: 질문 분석**
```
✅ 질문을 분석합니다.
   원본: "산림공간 디지털 플랫폼 산출물 목록"
   검색어: "산림공간 디지털 플랫폼 산출물"  ← 정규화 적용
   ⚠ "목록" 제거됨
```

정규화 미적용 시:
```
✅ 질문을 분석합니다.
   검색어: "산림공간 디지털 플랫폼 산출물 목록"
```

**2단계: 문서 검색**
```
✅ 관련 문서를 검색합니다.
   백엔드: OpenSearch
   검색 범위: 전체 색인 (PUBLIC + DEPT:infra)
   결과: 11개 청크 / 4개 문서
```

**3단계: 문서 읽기**
```
✅ 문서를 읽어옵니다.
   📄 ID_P05_테일러링내역서.pdf  (5 섹션)
   📄 RFP_산림플랫폼_v2.pdf     (2 섹션)
   📄 보안정책_v2.pdf            (4 섹션)
   ... +1개 더
```

**4단계: 내용 선별** (GENERATING에서만)
```
✅ 관련 내용을 선별합니다.
   선택된 문서: 1개
   검토 청크: 5개 → 상위 3개 선별
   (토큰 한도 기준)
```

**5단계: 답변 생성**
```
⏳ 답변을 생성합니다...
   모델: gpt-oss-20b
   예상 소요: 2~5초
```

또는 완료 후:
```
✅ 답변 생성 완료
   총 소요: 검색 142ms · LLM 2,341ms
```

## 4. 출처(Sources) 표시 설계

### 출처 항목 구조

```
📎 참조 출처 (2건)
─────────────────────────────────────────────
📄 ID_P05_테일러링내역서.pdf
   [PUBLIC] [sanrim-platform]
   5. 산출물 목록  ·  p.12  ·  점수 0.87   [상세 보기 →]

📄 ID_P05_테일러링내역서.pdf
   [PUBLIC] [sanrim-platform]
   3. 테일러링 내역  ·  p.8  ·  점수 0.81  [상세 보기 →]
```

### 출처 클릭 시 동작

출처 항목의 [상세 보기 →] 클릭:
- 우측 패널에 해당 청크 상세 표시
- 왼쪽 문서 카드에서 해당 문서 하이라이트

### 출처가 없는 경우

```
📎 참조 출처
─────────────────────────────────────────────
검색 결과가 없어 출처를 표시할 수 없습니다.
(LLM이 컨텍스트 없이 답변한 경우는 없습니다)
```

## 5. Chunk 상세 Side Panel

문서 카드 또는 출처 클릭 시 우측 패널이 Chunk 상세로 전환된다.

```
┌────────────────────────────────────────┐
│  📄 문서 상세              [← 닫기 ×] │
├────────────────────────────────────────┤
│  파일명:  ID_P05_테일러링내역서.pdf    │
│  경로:    public/sanrim-platform/      │
│  권한:    🔓 PUBLIC                    │
│  형식:    PDF                          │
│  색인일:  2026-05-13                   │
├────────────────────────────────────────┤
│  매칭 섹션 (5개)                       │
│  ────────────────────────────────────  │
│                                        │
│  ▼ 5. 산출물 목록  (p.12)  점수 0.87  │
│  ┌──────────────────────────────────┐  │
│  │ 본 프로젝트의 산출물 목록은 다음 │  │
│  │ WBS 기준에 따라 정의됩니다.     │  │
│  │ 1. WBS (작업 분류 체계)...      │  │
│  │ [더 보기 ...]                   │  │
│  └──────────────────────────────────┘  │
│                                        │
│  ▶ 3. 테일러링 내역  (p.8)  0.81      │
│  ▶ 1. 개요  (p.2)  0.74               │
│  ▶ 2. 적용 범위  (p.4)  0.68         │
│  ▶ 4. 품질 기준  (p.10)  0.61        │
│                                        │
├────────────────────────────────────────┤
│  [📋 파일 경로 복사]                   │
└────────────────────────────────────────┘
```

### Chunk 상세 표시 규칙

| 항목 | 표시 내용 |
|------|---------|
| chunk_text | 최대 300자 (더 보기 토글) |
| section_title | 섹션 제목 |
| page_no | 페이지 번호 |
| score | 검색 점수 |

**MVP 범위**: chunk_text를 그대로 표시.
PDF 페이지 이동 기능(뷰어 연동)은 Phase 3.

## 6. 디버그 패널 상세 설계

`ENABLE_RETRIEVAL_DEBUG=true`일 때 표시.

```
🔬 디버그 정보 (클릭하여 펼치기 ▶)
```

펼쳤을 때:

```
🔬 디버그 정보                        [접기 ▲]
─────────────────────────────────────────────────
🔍 검색 정보
  원본 질문:     "산림공간...목록" (앞 80자)
  검색 쿼리:     "산림공간...산출물"
  정규화 적용:   ✅ ("목록" 제거)
  검색 백엔드:   db
  매칭 청크:     11개  ·  매칭 문서: 4개

📋 청크별 결과
  ┌────────────────────────────────────────────┐
  │ 순위 │ 문서                │ 섹션       │ 점수 │ 매칭 필드        │
  │  1   │ ID_P05_테일러링...  │ 5.산출물목록│ 0.87 │ chunk_text       │
  │  2   │ ID_P05_테일러링...  │ 3.테일러링  │ 0.81 │ chunk_text,      │
  │      │                     │             │      │ section_title    │
  │  3   │ RFP_산림플랫폼_v2   │ 제안 배경   │ 0.61 │ chunk_text       │
  │ ...  │                     │             │      │                  │
  └────────────────────────────────────────────┘

🔑 하이라이트 키워드
  "산림공간", "디지털 플랫폼", "산출물"
─────────────────────────────────────────────────
```

디버그 패널은 **개발/스테이징 환경에서만** 표시 권장.
운영에서는 `ENABLE_RETRIEVAL_DEBUG=false` (기본값).

## 7. 빈 결과 / 오류 상태 상세

### 검색 결과 없음

```
🔍 관련 문서를 찾을 수 없습니다.

가능한 원인:
• 해당 키워드가 포함된 문서가 반입되지 않았습니다
• 권한 범위 내 문서에 관련 내용이 없습니다
• 검색어를 다르게 표현해보세요

검색어 제안:
• "산림" → "산림공간"  ← 더 구체적으로
• "제안서" → "제안요청서"  ← 정확한 문서명으로

[🔬 디버그 정보 보기]   검색어: "제안요청서"
```

### 문서 선택 후 청크 없음

```
⚠ 선택한 문서에서 관련 내용을 찾을 수 없습니다.

선택 문서: RFP_산림플랫폼_v2.pdf
상황: 이 문서는 검색 결과에 포함됐지만,
     선택된 문서만으로 재검색 시 충분한 청크가 없습니다.

[전체 결과로 다시 생성]  ← document_ids 없이 /generate 재호출
```

## 9. 접근성 (Accessibility)

| 항목 | 구현 |
|------|------|
| 스크린 리더 | `aria-label`로 점수 바, 체크박스, 상태 표현 |
| 색맹 대응 | 색상만이 아닌 텍스트(0.87, ✅, ❌)로 상태 표현 |
| 키보드 탐색 | Tab으로 문서 카드 이동, Space로 선택 |
| 포커스 표시 | 포커스 링 명시 (Tailwind `focus:ring`) |
| 로딩 상태 | `aria-busy="true"` + `aria-live="polite"` |

## 10. 반응형 대응 방침 (MVP)

MVP는 **데스크탑 전용** 설계 (최소 1280px 기준).
모바일/태블릿은 Phase 3 이후.

단, 1280px 미만 브라우저 접속 시:
```
⚠ ContextHub는 데스크탑 화면(1280px 이상)에 최적화되어 있습니다.
  더 나은 경험을 위해 데스크탑 브라우저를 사용해주세요.
```

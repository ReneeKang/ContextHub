# UI 화면 흐름 설계

## 개요

사용자가 질문을 입력하고 답변을 받기까지의
전체 화면 전환, 상태 변화, API 호출 순서를 정의한다.

---

## 1. 전체 흐름 다이어그램

```
[IDLE: 초기 화면]
  └─ 사용자: 에이전트 선택 (선택적)
  └─ 사용자: 필터 설정 (선택적)
  └─ 사용자: 질문 입력 + Enter or [문서 탐색]
        │
        ▼
[DISCOVERING: /discover 호출 중]
  └─ Retrieval Progress 패널: 1단계 "질문 분석 중..."
  └─ 문서 카드 영역: 스켈레톤 로딩
        │
        ├─ 결과 없음 → [EMPTY]
        └─ 결과 있음 ↓
        ▼
[DISCOVERED: 문서 후보 표시]
  └─ 문서 카드 목록 렌더링
  └─ 우측 패널: 검색 결과 요약 (문서 N개, 청크 N개)
  └─ Retrieval Progress: 2-3단계 표시
  └─ 사용자: 문서 체크박스 선택
  └─ 사용자: [선택 문서로 답변 생성] 클릭
        │
        ▼
[GENERATING: /generate 호출 중]
  └─ Retrieval Progress 패널: 4-5단계 진행
  └─ 답변 영역: "답변 생성 중..." 애니메이션
  └─ 선택한 문서 카드: 하이라이트 유지
        │
        ├─ LLM 오류 → [ERROR]
        └─ 성공 ↓
        ▼
[ANSWERED: 답변 완료]
  └─ 답변 텍스트 렌더링
  └─ 출처 목록 렌더링
  └─ 지연 시간 표시 (검색 Nms · LLM Nms)
  └─ 사용자: 출처 클릭 → 우측 패널: Chunk 상세 열림
  └─ 사용자: 새 질문 입력 → DISCOVERING으로 재시작
```

## 3. Retrieval Progress 단계 정의

| 단계 | 표시 조건 | 표시 내용 |
|------|----------|---------|
| 1) 질문 분석 | /discover 호출 직후 | 검색 쿼리 (정규화 후) |
| 2) 문서 검색 | 검색 진행 중 | 검색 백엔드, top_k_chunks |
| 3) 문서 읽기 | /discover 응답 수신 | 매칭 문서명 목록 (최대 3개) |
| 4) 내용 선별 | /generate 호출 직후 | "N청크 중 M개 선별" |
| 5) 답변 생성 | LLM 호출 중 | "답변 생성 중..." |
| ✅ 완료 | /generate 응답 수신 | "문서 N개 · 섹션 M개 참조" |

각 단계는 이전 단계가 완료되면 체크마크로 전환된다.

## 4. 우측 패널 상태 전환

```
화면 상태              우측 패널 내용
──────────────────────────────────────────────────
IDLE                   검색 가이드 + 색인 현황(placeholder)
DISCOVERING            검색 진행 중...
DISCOVERED             검색 결과 요약 (문서 수, 청크 수, 지연)
GENERATING             검색 결과 요약 유지 + LLM 대기 표시
ANSWERED               검색 결과 요약 유지
문서 [상세 보기] 클릭   Chunk 상세 패널 (슬라이드 인)
```

## 5. 오류 화면 상태

### 검색 결과 없음 (EMPTY)

```
📄 관련 문서 후보
─────────────────
  🔍 관련 문서를 찾을 수 없습니다.

  • 다른 키워드로 다시 검색해보세요
  • 문서가 반입되지 않았을 수 있습니다
  • 접근 권한이 없는 문서일 수 있습니다

  [🔬 디버그 정보 보기]
```

### LLM 오류 (ERROR)

```
💬 답변
─────────────────
  ⚠ 답변 생성에 실패했습니다.

  원인: LLM 서버 응답 없음 (timeout)
  trace_id: a1b2c3d4

  [🔄 다시 시도]
```

## 6. 에이전트 선택 드롭다운

```
[NAS RAG 에이전트 ▼]
─────────────────────
✅ NAS RAG 에이전트     ← 현재 선택, 활성
   사내 문서 기반 검색/답변

── Phase 2에서 추가 ──
⬜ 로그 분석 에이전트   (준비 중)
⬜ 표준 검토 에이전트   (준비 중)
```

MVP에서는 단일 에이전트만 있고, 나머지는 `(준비 중)` 표시로 자리만 잡는다.
선택 변경 시 필터 기본값과 시스템 프롬프트가 전환되는 구조 (Phase 3).

## 7. 필터 바 상세

```
[📁 프로젝트 ▼]  [📄 파일유형 ▼]  [🔒 권한 ▼]  [X 필터 초기화]
```

### 프로젝트 드롭다운

```
📁 프로젝트
─────────────────
☑ (전체)
☐ sanrim-platform
☐ cloud-migration
☐ (프로젝트 없는 문서)
```

`/discover` 응답의 `project_key` 값들을 집계하여 동적으로 생성.

### 파일유형 드롭다운

```
📄 파일유형
─────────────────
☑ (전체)
☐ PDF
☐ DOCX
☐ HWP
☐ TXT
```

### 권한 드롭다운

```
🔒 권한 범위
─────────────────
☑ (전체 접근 가능)
☐ PUBLIC만
☐ DEPT 포함
☐ PRIVATE 포함
```

필터는 클라이언트에서 `/discover` 결과를 후처리하는 방식으로 적용 (재검색 없음).

## 8. 키보드 접근성

| 키 | 동작 |
|----|------|
| `Enter` | 검색 실행 |
| `Escape` | 드롭다운 닫기, Side Panel 닫기 |
| `Tab` | 문서 카드 간 포커스 이동 |
| `Space` | 포커스된 체크박스 토글 |
| `Ctrl+K` | 검색창으로 포커스 이동 |

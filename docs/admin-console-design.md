# 관리자 콘솔 화면 설계

## 개요

운영자가 에이전트·문서·LLM·검색 품질을 관리하는
관리자 콘솔 화면을 Phase별로 설계한다.

---

## Phase 1 MVP: 관리자 핵심 기능

### A. 에이전트 관리 (`/admin/agents`)

#### 에이전트 목록 화면

```
┌─────────────────────────────────────────────────────────┐
│  🤖 에이전트 관리                       [+ 에이전트 추가] │
├─────────────────────────────────────────────────────────┤
│  No │ 에이전트명          │ 지식 DB     │ 상태  │ 수정  │
├─────────────────────────────────────────────────────────┤
│  1  │ NAS RAG 에이전트    │ NAS 전체    │ 🟢 활성│ [수정]│
│  2  │ (준비중) 로그 분석  │ -           │ 🔴 비활│ [수정]│
└─────────────────────────────────────────────────────────┘
```

| 컬럼 | 설명 |
|------|------|
| 에이전트명 | 사용자에게 보여지는 이름 |
| 지식 DB | 연결된 데이터셋/경로 (현재: NAS 공식 반입 폴더 전체) |
| 상태 | 활성/비활성 토글 |
| 수정 | 에이전트 상세 모달 열기 |

**MVP 범위**: 에이전트 1개(NAS RAG) 고정. 목록 화면은 상태 확인용.
에이전트 추가/수정 모달은 Phase 2에서 구현.
